## Paragraphs

A paragraph is a run of lines with no blank line between them. These two lines are one paragraph, and the line break between them is
not shown. A blank line starts a new paragraph.

This is the second paragraph.

## Bold and italic

**Bold** is two asterisks on each side, *italic* is one asterisk (or an underscore: _also italic_), and ***both*** is three. Use bold for names and labels, and italic for emphasis or titles, and use neither for whole paragraphs.

## Inline code

Use backticks for a file name such as `saves/SAVE0`, a setting such as `fov: 90`, or something typed exactly. A line with a backtick inside it needs more backticks around it: ``a `quoted` word``.

## Characters

Quotes "like these" and an apostrophe's shape come out as typed. A backslash does not escape a mark, so to show an asterisk or a bracket exactly, put it in backticks: `2 * 3`.
