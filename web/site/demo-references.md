## What builds it

The **References** section at the bottom of this page is not written here. The site builds it from the links in the text and from the `related:` line in the front matter above, and it lists each link once, in the order it first appears.

The text links to a guide page ([[Renown]]), a Site Guide page ([[site:Extended formatting]]), a Patch Notes topic ([[topic:Renown]]), a patch ([[patch:0.1.8859]]) and an outside website ([example.com](https://example.com)).

## Pages that are only related

The `related:` line names pages that do not belong in a sentence: here a guide page, a Site Guide page, a topic and a patch. A name with no prefix is a Game Guide page, and the others need `guide:`, `site:`, `topic:` or `patch:` in front. They appear in the same sections at the bottom as linked ones.

## What each part lists

| Part | What it lists |
|---|---|
| Game Guide | the guide pages linked, each with its summary |
| Site Guide | the Site Guide pages linked |
| Patch Notes | topics and patches linked, with when each was last changed |
| External Links | the outside websites linked |

Scroll to the bottom to see the sections.
